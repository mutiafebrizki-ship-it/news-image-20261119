Sum up the world's news of Thursday 19 November 2026 in one image: a newspaper
front page. Top story: the Trump–Xi–Putin trilateral meeting at the APEC summit
in Shenzhen. Also in the picture: Israel's ground operation and flooding in
Gaza, the Crimean Bridge attacked again, and Anthropic's record $81.3 billion
IPO — the biggest ever.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes the image to `out/entry.png` (in the grader it writes
`/output/entry.png`). The program is standard library only, uses no network,
and writes the same bytes on every run.
